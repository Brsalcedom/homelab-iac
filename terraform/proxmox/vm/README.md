# Proxmox VM — OpenTofu configuration

QEMU virtual machines cloned from a Rocky Linux cloud-init template, using the `proxmox/vm-cloud-init` module from [Brsalcedom/tf-modules](https://github.com/Brsalcedom/tf-modules). State is stored in Cloudflare R2.
